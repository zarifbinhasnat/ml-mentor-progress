# Day 82 — Concept 82: GAN Instability & Wasserstein GAN

## 🧠 CONCEPT OF THE DAY

**Intuition.** Yesterday you built the minimax game: a forger (G) and an art
authenticator (D) locked in an arms race. Today's problem is that the arms
race is *unfair by construction* early on. If the forger's fakes look
nothing like real paintings yet, the authenticator doesn't need to be
subtle — it can say "100% fake" with total confidence everywhere it looks.
A confident-everywhere classifier is *flat* everywhere: its output barely
changes as the forger nudges a fake slightly closer to real. No slope, no
gradient, no lesson for the forger. The discriminator "wins" so completely
that it stops teaching.

Wasserstein GAN reframes the judge's job entirely. Instead of asking "is
this real or fake?" (a probability, bounded in [0,1], free to saturate), it
asks "how far is this fake from looking real, as a *distance*?" — literally
the minimum cost to shovel probability mass from the fake pile onto the
real pile (the Earth Mover's / Wasserstein distance). A distance can't
saturate — it just keeps shrinking as G improves, so there's always a
nonzero gradient pointing G in the right direction, no matter how bad G
currently is.

**The math.** The vanilla GAN objective is:

$$\min_G \max_D \; \mathbb{E}_{x\sim p_r}[\log D(x)] + \mathbb{E}_{z\sim p_z}[\log(1-D(G(z)))]$$

With an optimal $D$, this objective is (up to a constant) the Jensen-Shannon
divergence between $p_r$ (real data distribution) and $p_g$ (generator's
distribution). JS divergence is *locally constant* ($\log 2$) whenever
$p_r$ and $p_g$ have disjoint or barely-overlapping support — which is
almost always true in high dimensions early in training. Constant loss ⇒
zero gradient ⇒ generator stalls.

The Wasserstein-1 (Earth Mover's) distance instead is:

$$W(p_r, p_g) = \inf_{\gamma \in \Pi(p_r,p_g)} \mathbb{E}_{(x,y)\sim\gamma}\big[\lVert x-y\rVert\big]$$

where $\Pi(p_r,p_g)$ is the set of all joint distributions ("transport
plans") with those two marginals. This infimum is intractable directly, but
the Kantorovich–Rubinstein duality rewrites it as a supremum over
1-Lipschitz functions:

$$W(p_r,p_g) = \sup_{\lVert f\rVert_L \le 1} \; \mathbb{E}_{x\sim p_r}[f(x)] - \mathbb{E}_{x\sim p_g}[f(x)]$$

That $f$ is exactly what the "discriminator" becomes — except it's no
longer a probability, it's a scalar score, so we rename it the **critic**.
The WGAN objective is:

$$\min_G \max_{D \in \{1\text{-Lipschitz}\}} \; \mathbb{E}_{x\sim p_r}[D(x)] - \mathbb{E}_{z\sim p_z}[D(G(z))]$$

The 1-Lipschitz constraint ($\lVert D(x_1)-D(x_2)\rVert \le \lVert x_1-x_2\rVert$
for all $x_1,x_2$) is what stops the critic from becoming an
infinitely-steep step function — it's the mathematical leash that keeps a
usable gradient available everywhere. Two ways to enforce it, both of which
you'll meet in practice:

- **Weight clipping** (original WGAN): after every update, clip all critic
  weights to $[-c, c]$. Crude — it caps the *function class*, not the
  Lipschitz constant directly, and tends to push weights to the clip
  boundary, hurting capacity.
- **Gradient penalty** (WGAN-GP, the one you'll actually use): softly
  penalize the critic whenever its gradient norm deviates from 1 at points
  $\hat{x}$ interpolated between real and fake samples:

$$\mathcal{L}_{GP} = \lambda \, \mathbb{E}_{\hat{x}}\Big[\big(\lVert \nabla_{\hat{x}} D(\hat{x})\rVert_2 - 1\big)^2\Big]$$

**Why it matters / where it leads.** WGAN doesn't fully solve GAN training
(mode collapse, hyperparameter sensitivity, and instability all persist to
some degree), but it reframes the loss as a *meaningful distance metric*
that correlates with sample quality — for the first time in the GAN
literature you can actually watch the loss curve and believe it. That
distance-based framing is also your bridge to tomorrow: diffusion models
sidestep the adversarial game entirely by directly regressing a score/noise
target, trading GAN instability for a slower-but-stable iterative denoising
process. Interviewers love this concept because it tests whether you
understand *why* a loss function's shape — not just its value — determines
trainability.

**Interview question:** *Why does the vanilla GAN discriminator's optimal
solution lead to a vanishing gradient for the generator, and what specific
mathematical property of the Wasserstein distance avoids that failure mode?*
(Answer at the very bottom.)

## 🐍 PYTHONIC EDGE

The gradient penalty term requires differentiating *through* a gradient —
a second-order autograd call. This trips people up constantly because the
naive way silently detaches the graph.

```python
import torch

# BAD: gradient computed but the computational graph needed to
# backprop *through* this gradient (into critic.parameters()) is lost,
# because create_graph defaults to False.
def gradient_penalty_bad(critic, real, fake):
    eps = torch.rand(real.size(0), 1, 1, 1)   # random weight per sample, broadcastable
    x_hat = eps * real + (1 - eps) * fake     # * is elementwise here, not matmul (that's @)
    x_hat.requires_grad_(True)                # trailing _ => in-place: mutates x_hat itself
    scores = critic(x_hat)                    # __call__ on the module -> wraps forward(), runs hooks

    grads = torch.autograd.grad(
        outputs=scores, inputs=x_hat,
        grad_outputs=torch.ones_like(scores),
        create_graph=False,                   # <-- bug: no graph, .backward() later can't reach critic's weights
    )[0]                                       # autograd.grad returns a tuple; unpack the single element
    penalty = ((grads.norm(2, dim=1) - 1) ** 2).mean()
    return penalty


# CLEAN: create_graph=True keeps the penalty differentiable w.r.t.
# the critic's own parameters, which is the entire point of WGAN-GP.
def gradient_penalty(critic, real, fake):
    eps = torch.rand(real.size(0), *[1] * (real.dim() - 1))  # * unpacks trailing 1s to match real's rank
    x_hat = (eps * real + (1 - eps) * fake).requires_grad_(True)
    scores = critic(x_hat)

    grads, = torch.autograd.grad(               # tuple unpacking with a trailing comma == take element 0
        outputs=scores, inputs=x_hat,
        grad_outputs=torch.ones_like(scores),    # dL/dscores seed, since scores isn't scalar
        create_graph=True,                       # keep graph alive -> penalty backprops into critic weights
        retain_graph=True,
    )
    grad_norm = grads.view(grads.size(0), -1).norm(2, dim=1)  # -1 in view() means "infer this dim"
    return ((grad_norm - 1) ** 2).mean()
```

`torch.autograd.grad(..., create_graph=True)` is the general pattern
whenever a loss term is itself a function *of a gradient* — you'll see the
identical trick again for meta-learning (MAML) and for score-matching
objectives in diffusion models tomorrow.

## 📡 SIGNAL LAB

**Problem.** You suspect two batches of generated images came from
different GAN checkpoints — one earlier in training (blurrier, spectrally
duller) and one later (sharper, but with the checkerboard/grid artifacts
GANs are notorious for in the high-frequency band). You don't have labels,
just the images. Can Wasserstein distance itself give you a cheap,
principled way to quantify "how different" two batches are, in the
*frequency domain* specifically?

**Solution.** Take the radially-averaged power spectral density (PSD) of
each image — collapse the 2D FFT magnitude into a 1D profile over spatial
frequency $|k|$ by averaging power over concentric rings. Average that
profile across each batch to get $\text{PSD}_A(k)$ and $\text{PSD}_B(k)$,
two 1D distributions over frequency. Since both are already 1D, non-negative,
and defined on the same ordered support ($k = 0 \ldots k_{max}$), the
1-Wasserstein distance between them has a closed form — no neural critic
needed, no optimization:

$$W_1(\text{PSD}_A, \text{PSD}_B) = \int_0^{k_{max}} \big| \text{CDF}_A(k) - \text{CDF}_B(k) \big| \, dk$$

i.e. the L1 distance between their *cumulative* PSDs. This is exactly the
1D special case of the same Earth Mover's distance from today's lesson:
"cost to reshape one spectral profile into the other." A large $W_1$
concentrated at high $k$ tells you the checkpoints differ specifically in
high-frequency content — precisely the checkerboard-artifact signature GAN
upsampling (transposed conv, Concept 43) leaves behind, and precisely the
kind of statistic forensic detectors exploit to flag GAN-generated images
in the first place.

**So what:** the exact same "distance between distributions, not just a
classifier probability" idea that stabilizes GAN training also gives you a
principled, differentiable, artifact-localizing similarity metric for your
own frequency-domain forensics work — same math, wildly different
application.

## 🏋️ THE GAUNTLET

**Minimum Cost to Equalize Two Histograms (1D Earth Mover's Distance)**

You are given two integer arrays `A` and `B`, each of length `n`, where
`A[i]` and `B[i]` are the amount of "mass" (e.g. probability mass ×10000,
or literal units of stock) sitting at position `i` along a 1D line.
`sum(A) == sum(B)`. In one move you may shift one unit of mass from
position `i` to an adjacent position `i±1`; the cost of that move is 1.
Return the minimum total number of unit-moves required to transform
histogram `A` into histogram `B`.

**Constraints:** `1 <= n <= 2 * 10^5`, `0 <= A[i], B[i] <= 10^6`,
`sum(A) == sum(B) <= 10^12` (use 64-bit integers).

**Hint 1:** Don't think about individual units of mass moving — think about
the *net* surplus or deficit at each prefix of the array. Define
`diff[i] = A[i] - B[i]`.

**Hint 2:** Let `prefix[i] = diff[0] + diff[1] + ... + diff[i]`. This
`prefix[i]` represents the total mass that *must* cross the boundary
between position `i` and `i+1`, in either direction. Why must this exact
amount cross, no more, no less?

**Hint 3:** The answer is `sum(|prefix[i]|)` over all boundaries
`i = 0 .. n-2`. Convince yourself the greedy "always resolve the deficit at
the current position using the nearest available surplus" strategy is
optimal, and that it produces exactly this prefix-sum formula.

**Pattern:** Prefix sum / greedy transport (this is literally the 1D
Wasserstein / Earth Mover's distance you just met in the lesson).
**Target complexity:** O(n) time, O(1) extra space (besides input).

🔓 GAUNTLET SOLUTION

```cpp
#include <bits/stdc++.h>
using namespace std;

long long minCostToEqualize(vector<long long>& A, vector<long long>& B) {
    int n = A.size();
    long long total_cost = 0;
    long long running_diff = 0; // net surplus (+) or deficit (-) carried across the current boundary

    for (int i = 0; i < n - 1; ++i) {
        running_diff += A[i] - B[i];
        total_cost += llabs(running_diff); // mass that must cross boundary i -> i+1
    }
    // No cost term for the last index: since sum(A) == sum(B),
    // the running_diff after processing index n-1 is guaranteed to be 0
    // (nothing left to cross past the end), so it's excluded by the loop bound.

    return total_cost;
}

int main() {
    int n;
    cin >> n;
    vector<long long> A(n), B(n);
    for (auto &x : A) cin >> x;
    for (auto &x : B) cin >> x;
    cout << minCostToEqualize(A, B) << "\n";
    return 0;
}
```

Why this is optimal: any unit of mass that starts on the deficit side of
boundary `i` and must end on the surplus side (or vice versa) has to cross
that boundary at least once — there's no way around it in 1D. The prefix
sum `running_diff` at boundary `i` is exactly the net amount that *must*
cross there, so `sum(|running_diff|)` is both a valid lower bound (each
crossing is necessary) and achievable (route each deficit to its nearest
available surplus, which never requires crossing any boundary more than
once in the same direction). This is the discrete analogue of the integral
formula in today's Signal Lab.

💡 CONCEPT ANSWER

At the optimal discriminator $D^*(x) = \frac{p_r(x)}{p_r(x)+p_g(x)}$, the
GAN value function reduces (up to an additive constant) to
$2 \cdot JS(p_r \| p_g) - \log 4$. When $p_r$ and $p_g$ have disjoint or
near-disjoint support — the norm in high-dimensional image space, especially
early in training — the Jensen-Shannon divergence is *locally constant*
at $\log 2$ regardless of exactly how far apart the distributions are, so
its gradient with respect to the generator's parameters is zero almost
everywhere: the generator gets no signal about *which direction* to move.
The Wasserstein-1 distance doesn't have this flat-region problem because,
via the Kantorovich–Rubinstein dual, it's defined as a supremum over
1-Lipschitz functions — and a 1-Lipschitz function's output changes
*continuously and boundedly* with the input distance, by definition. So
$W(p_r,p_g)$ shrinks smoothly and continuously as the generator's
distribution moves closer to the real one, even while the two still have
disjoint support, giving the generator a well-behaved, non-vanishing
gradient throughout training.
